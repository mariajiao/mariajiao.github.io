Central Processing Unit

Technology Logisim
Type Digital Systems Project

Overview

Designed and implemented a fully functional Central Processing Unit (CPU) in Logisim, featuring register files, ALU, data memory, program counter, and barrel shifter. This project demonstrates comprehensive understanding of computer architecture and digital systems design.

Key Components

  • Register files for data storage and retrieval
  • Arithmetic Logic Unit (ALU) for mathematical and logical operations
  • Data memory for storing and accessing program data
  • Program counter for instruction sequencing
  • Barrel shifter for efficient bit manipulation operations
  • Control logic for various instruction types with I/O and memory operations

Technical Details

The CPU was designed to handle multiple instruction types including arithmetic operations, data transfer operations, I/O operations, and memory access instructions. The control unit manages the execution of instructions by coordinating all CPU components.
